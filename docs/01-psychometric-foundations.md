# Fundamentos psicométricos para investigar antes de construir TestPsico

**Decisión primero:** TestPsico se encuentra en estado de investigación; todavía no existe un instrumento validado ni una fase de implementación iniciada. El primer propósito propuesto es la orientación vocacional/educativa de bajo riesgo para explorar carreras y programas de toda la UAGRM. La página oficial de Orientación Vocacional demuestra un contexto institucional de acompañamiento y menciona un “Test Psicotécnico”, pero no valida ningún instrumento de TestPsico [S28].

Una cadena de medición útil es:

> **Constructo → indicadores observables → tareas/ítems → puntuaciones → interpretación → uso**

Cada flecha exige evidencia. Una pregunta plausible, un catálogo institucional o una interfaz atractiva no justifican por sí solos la interpretación final.

## Ruta de investigación

1. Definir el constructo, la interpretación permitida, el uso y la población.
2. Separar la evidencia de las puntuaciones de la evidencia de comparación con perfiles educativos.
3. Diseñar muestreo y respuesta-proceso para la población completa a la que se quiera generalizar.
4. Verificar y versionar el catálogo autorizado antes de comparar afinidades con carreras o programas.
5. Pilotear, estimar incertidumbre y documentar límites antes de cualquier implementación.

## Tres obligaciones de evidencia

| Línea de evidencia | Pregunta que puede responder | Lo que no demuestra |
| --- | --- | --- |
| **Medición de puntuaciones** | ¿Las respuestas representan los constructos definidos con precisión suficiente para el uso declarado? | No demuestra que una carrera sea adecuada ni que la puntuación prediga éxito académico, empleabilidad o admisión. |
| **Comparación con perfiles de programa** | ¿El `program_profile` describe de forma trazable un programa autorizado y la salida conecta respuestas, razones y fuentes? | No valida el instrumento ni convierte una afinidad en una decisión individual. |
| **Uso en toda la UAGRM** | ¿La muestra, el idioma, la modalidad, el sitio, el nivel y las condiciones de acceso representan a la población sobre la que se quiere hablar? | La evidencia de una facultad, sede o grupo conveniente no generaliza automáticamente a toda la UAGRM. |

Estas líneas deben registrarse por separado. La existencia de oferta académica responde qué programas pueden aparecer; la psicometría responde qué significan las respuestas; el muestreo y la generalización responden para quiénes es defendible la interpretación.

## Estado actual y límites

| Área | Estado actual |
| --- | --- |
| Propósito | Hipótesis de orientación vocacional/educativa exploratoria y de bajo riesgo; requiere aprobación institucional. |
| Poblaciones | Incluye como poblaciones previstas a estudiantes de secundaria, postulantes a la UAGRM y otras personas interesadas, con muestreo y salvaguardas por definir. |
| Cobertura académica | Toda la oferta autorizada de la UAGRM. Facultad, sede o sitio, nivel, modalidad y disponibilidad son metadatos y posibles filtros explicativos, no un pre-filtro obligatorio. |
| Instrumento y puntuaciones | No establecidos ni validados para TestPsico. |
| Perfiles de programa | Deben ser educativos, revisados, versionados y trazables; todavía no se presume que existan perfiles aprobados. |
| Normas, percentiles y cortes | No existen valores productivos justificados. Un ejemplo sintético no es una norma UAGRM. |
| Implementación | Ninguna fase ha comenzado. La implementación futura depende de puertas de investigación explícitas. |

No se debe afirmar “la carrera correcta”, admisión, elegibilidad, rendimiento académico, empleabilidad, diagnóstico clínico ni una decisión de alto impacto.

## 1. Constructos y operacionalización

Un **constructo** es el atributo o proceso que una puntuación pretende representar. “Encaje”, “resiliencia” o “liderazgo” son etiquetas demasiado amplias hasta que se define qué incluyen, qué excluyen y para qué uso se medirán.

Antes de redactar un ítem, registrar:

| Pregunta | Respuesta necesaria |
| --- | --- |
| ¿Cuál es el constructo? | Definición acotada, incluidos sus límites. |
| ¿Qué interpretación se permite? | Qué puede sugerir una puntuación alta, baja o diferenciada. |
| ¿Cuál es el uso? | Orientación exploratoria, investigación, retroalimentación u otro uso explícito. |
| ¿Quiénes integran la población? | Edad, trayectoria educativa, idioma, cultura, acceso, modalidad y contexto. |
| ¿Qué consecuencias tiene el error? | Qué daño puede causar interpretar o usar mal la puntuación. |
| ¿Qué evidencia se necesita? | Contenido, respuesta-proceso, estructura interna, relaciones con otras variables, consecuencias y generalización [S1][S3]. |

La **operacionalización** transforma el constructo en indicadores observables o elicitable mediante una respuesta definida. “Compara dos alternativas documentadas según restricciones explícitas” es más revisable que “es analítico”. Cada indicador debe declarar qué no permite inferir sobre la persona.

```text
constructo definido
  → indicador de conducta, preferencia o respuesta
    → tarea/ítem y regla de respuesta
      → componente de puntuación
        → interpretación y uso permitido
          → evidencia y limitación
```

Si no se puede explicar un enlace, se marca como hipótesis o vacío de evidencia; no se rellena con intuición.

## 2. Teoría clásica de los tests (`CTT`)

La `CTT` representa la puntuación observada como un componente relativamente estable más error de medición:

```text
puntuación observada = componente de puntuación verdadera + error
```

El componente verdadero no es una esencia directamente observable: es una expectativa dependiente del modelo sobre mediciones comparables repetidas. El error puede provenir del muestreo de ítems, la ocasión, la persona evaluadora, la administración, la puntuación, la tecnología y otras fuentes.

La `CTT` ayuda a preguntar:

- ¿Los ítems pretenden medir el mismo componente?
- ¿La puntuación es suficientemente consistente para el uso declarado?
- ¿Qué incertidumbre debe acompañar a una puntuación individual?
- ¿Cambia el comportamiento entre poblaciones, ocasiones, formularios o modalidades?

Un coeficiente de confiabilidad describe la consistencia o dependencia bajo condiciones definidas; no es una propiedad universal del instrumento y no prueba validez. Puede variar con población, rango de puntuaciones, longitud, administración y puntuación.

## 3. Confiabilidad, `SEM` e incertidumbre

La **confiabilidad** pregunta qué parte de la variación observada es dependiente para un diseño de medición concreto. El coeficiente pertinente depende de lo que se quiere generalizar: consistencia interna, estabilidad temporal, acuerdo entre evaluadores u otra fuente de precisión [S1].

Una aproximación habitual del error estándar de medición es:

```text
SEM = SD × √(1 − confiabilidad)
```

Es una ayuda de planificación, no una licencia para ocultar supuestos. Se deben informar la desviación estándar, la estimación de confiabilidad, la población, la escala y las condiciones. Una puntuación individual nunca debe tratarse como exacta.

Todo reporte de puntuación debe hacer visible:

- escala y dirección;
- estimación de confiabilidad y población de estimación;
- `SEM` u otro índice de precisión;
- condiciones a las que aplica;
- incertidumbre de intervalos o clasificaciones, si existieran;
- lo que la puntuación no puede establecer.

La precisión necesaria para una conversación de orientación no es automáticamente suficiente para admisión, contratación o una decisión de alto impacto.

## 4. Validez como evidencia para una interpretación y un uso

La validez no es una etiqueta permanente del test. Es la fuerza de la evidencia y de la teoría que respaldan una interpretación de las puntuaciones para un uso, una población y unas condiciones concretas [S1][S3].

El argumento de validez debe preguntar:

1. **Contenido:** ¿Las tareas representan el constructo y su dominio relevante?
2. **Respuesta-proceso:** ¿Las personas entienden y responden con los procesos previstos?
3. **Estructura interna:** ¿Las relaciones entre ítems y dominios apoyan las dimensiones propuestas?
4. **Relaciones con otras variables:** ¿Aparecen relaciones esperadas, con diseño e incertidumbre apropiados?
5. **Consecuencias y uso:** ¿La interpretación y sus efectos son apropiados, accesibles y justos para el propósito declarado?
6. **Generalización:** ¿La evidencia aplica a las poblaciones, sedes, niveles, modalidades y condiciones de acceso sobre las que se quiere informar?

Ninguna correlación, solución factorial, confiabilidad, afirmación de un proveedor o interfaz completa el argumento. La evidencia tampoco se transporta automáticamente a otra población, idioma, modalidad o nivel de riesgo.

## 5. Comparación con perfiles educativos y recomendación

La evidencia psicométrica y la evidencia de recomendación son distintas:

- La primera estudia si las respuestas y puntuaciones tienen el significado declarado.
- La segunda estudia si cada `program_profile` se deriva de una fuente institucional autorizada, si el mapeo entre dominios y perfiles es comprensible y si las personas entienden la salida como exploración.
- La tercera estudia el uso en toda la UAGRM: cobertura muestral, precisión por subgrupo, accesibilidad, idioma, modalidad y límites de generalización.

La salida futura debe ser un conjunto plural o un orden exploratorio de afinidades, con razones, incertidumbre, limitaciones y preguntas para seguir explorando. No debe presentarse como una clasificación definitiva ni como una propiedad fija de la persona.

## 6. Cobertura UAGRM, catálogo y generalización

La población de interés no puede reducirse a una facultad conveniente. Puede incluir estudiantes de secundaria, postulantes a la UAGRM y otras personas interesadas en realizar el test psicotécnico, siempre que la institución defina población, consentimiento, acceso y propósito. La cobertura y la recolección pueden organizarse por etapas según facultad, sede/sitio, nivel, modalidad o disponibilidad; esa es una estrategia de investigación y **no** autoriza a usar la facultad como pre-filtro obligatorio de recomendaciones.

La oferta pública disponible presenta incertidumbre que debe resolverse antes de recomendar:

- La página oficial de admisiones informa 18 facultades y 69 programas de formación profesional en Santa Cruz de la Sierra [S29]. Es un dato institucional contextual, no necesariamente un catálogo universitario completo y no incluye metadatos confiables de versión o vigencia.
- La página pública de carreras expone aproximadamente 80 entradas o páginas, con repeticiones por facultad o sitio y campos de texto desiguales [S30]. No constituye por sí sola un catálogo versionado confiable.
- La discrepancia no se resuelve eligiendo uno de los números. Antes de cualquier recomendación se requiere un catálogo institucional autorizado, reconciliado y versionado, con identificadores estables, estado, responsable y fechas de vigencia/efectividad.

### Muestreo y límites

El plan debe especificar marco muestral, cobertura de facultades y sitios, niveles educativos, modalidades, disponibilidad de programas, idioma, acceso tecnológico y subgrupos relevantes. Un piloto de una sola facultad puede aportar evidencia local para esa muestra, pero no evidencia de uso en toda la UAGRM.

El estudio local sobre 122 postulantes de la Facultad de Ciencias Económicas y Empresariales, realizado en marzo de 2023, fue descriptivo, transversal y no experimental; observó dimensiones personales, familiares y socioeconómicas, con predominio de factores familiares y socioeconómicos [S31]. Es contexto local y una hipótesis para investigar, no una base para asignar pesos universales, afirmar causalidad o generalizar a toda la UAGRM.

## 7. Equidad, accesibilidad y comparabilidad

La equidad y la accesibilidad son requisitos de medición. No se debe evaluar a una persona por barreras irrelevantes de idioma, discapacidad, interfaz, tecnología, cultura o condiciones de administración [S1][S5][S6].

- La **varianza irrelevante al constructo** aparece cuando el resultado depende de una barrera ajena a lo que se pretendía medir.
- El **funcionamiento diferencial del ítem (`DIF`)** es una señal para investigar, no una prueba completa de discriminación o injusticia [S1][S11][S12].
- La **invarianza de medición** pregunta si la estructura y los parámetros son comparables para un propósito de comparación definido.
- La decisión de equidad es sustantiva y contextual; la paridad estadística por sí sola no la resuelve.

El trabajo debe incluir representación, revisión lingüística y cultural, pruebas de accesibilidad, reglas de acomodación, datos faltantes, precisión por subgrupo y respuesta documentada ante hallazgos negativos o mixtos.

## 8. Localización, calibración y normas

Una adaptación en español para UAGRM es una adaptación local y una base de evidencia; no es automáticamente un instrumento nacional. Las `Guidelines for Translating and Adapting Tests` de la ITC orientan traducción, revisión independiente, reconciliación, adaptación cultural, respuesta-proceso y control de versiones [S27]. No se deben copiar ítems, manuales, normas ni reglas protegidas.

**Calibrar** estima parámetros de ítems o modelos bajo datos, población, modelo y condiciones específicas. **Normar** describe la distribución de puntuaciones de una población de referencia definida. Ninguna operación crea validez para otro uso o población. Los datos UAGRM no se convierten automáticamente en normas bolivianas, percentiles nacionales o puntos de corte.

## 9. Administración, puntuación, reporte y privacidad

La administración forma parte del modelo de medición. Se deben definir modalidad, instrucciones, identidad y seguridad, tiempos, acomodaciones, interrupciones, repeticiones, puntuación y manejo de faltantes antes del piloto [S5][S6].

La puntuación debe ser reproducible y auditable: versionar ítems, claves o rúbricas protegidas, transformaciones, reglas de faltantes, instrucciones y correcciones. Separar respuestas de datos identificables y conservar proveniencia suficiente para reproducir un reporte sin exponer contenido protegido.

El reporte debe declarar propósito, población de referencia si existe, incertidumbre, condiciones, limitaciones y próximos pasos. Debe ofrecer razones comprensibles y preguntas de exploración, nunca una identidad fija ni “la carrera correcta” [S4][S7].

Antes de recolectar datos identificables o sensibles, se requieren revisión ética/institucional y de gobierno de datos, minimización, consentimiento o asentimiento cuando corresponda, acceso, retención, eliminación y atención de solicitudes. Para menores y personas jóvenes, el proceso de comprensión, consentimiento/asentimiento y salvaguardas debe estudiarse específicamente; no se debe asumir que el procedimiento de adultos es suficiente [S24][S25]. Engram no es un almacén para respuestas de participantes ni para datos identificables [S36][S37][S38].

## 10. Normas, puntuaciones estándar, percentiles y cortes

| Término | Significado | Límite |
| --- | --- | --- |
| Norma | Comparación descriptiva con una población de referencia y condiciones definidas. | No es diagnóstico, requisito académico ni estándar universal. |
| Puntuación estándar | Transformación relativa a una media y dispersión especificadas. | No añade validez ni elimina error. |
| Percentil | Posición relativa dentro de una distribución de referencia. | No es una unidad de intervalo ni expresa probabilidad de éxito. |
| Punto de corte | Umbral para clasificar o decidir según un propósito declarado. | Exige diseño de decisión, consecuencias y evidencia específica [S1][S3]. |

TestPsico no tiene normas ni cortes de producción justificados. Una cifra sintética solo puede ser un ejemplo explícitamente marcado como tal.

## 11. Desarrollo de ítems y análisis

El desarrollo debe seguir la matriz de especificación:

1. Definir faceta del constructo, indicador, respuesta y regla de puntuación.
2. Redactar contenido original con una demanda clara.
3. Revisar cobertura, accesibilidad, lenguaje, cultura y demandas irrelevantes.
4. Realizar entrevistas cognitivas o revisión de respuesta-proceso.
5. Pilotear en condiciones previstas.
6. Examinar faltantes, patrones, dificultad, discriminación, distractores, tiempo y subgrupos.
7. Revisar con una justificación registrada; no borrar evidencia incómoda en silencio.

La `CTT` y la `IRT` pueden apoyar análisis distintos. La `IRT` requiere constructo definido, datos pertinentes, supuestos verificables y personal capacitado; no es automáticamente superior ni compensa una muestra pequeña o no representativa [S11][S12]. La `EFA` y la `CFA` investigan o evalúan estructuras, pero no prueban por sí solas que un constructo sea sustantivamente correcto.

## Puerta mínima antes de cualquier implementación

Ninguna fase de implementación debe comenzar hasta que exista evidencia o una limitación explícita para cada punto:

- [ ] Propósito, interpretación, uso, población, nivel de consecuencias y límites están aprobados para investigación.
- [ ] La cobertura pretende toda la UAGRM y documenta qué etapas o subgrupos quedan fuera.
- [ ] El catálogo autorizado está reconciliado, versionado y tiene IDs, estados y fechas de vigencia.
- [ ] Cada `program_profile` tiene fuente, versión, responsable, revisión y límites de afirmación.
- [ ] Cada medida tiene matriz de especificación, contenido original, reglas reproducibles y proveniencia.
- [ ] Respuesta-proceso, comprensión, accesibilidad y condiciones para menores/ jóvenes fueron revisadas cuando correspondan.
- [ ] Precisión, incertidumbre, estructura y validez se reportan para la población estudiada.
- [ ] La salida es plural, explicable y exploratoria; no afirma admisión, éxito, empleabilidad, diagnóstico ni decisión de alto impacto.
- [ ] Privacidad, consentimiento/asentimiento, seguridad, retención, eliminación, usuarios autorizados y retroalimentación están definidos.
- [ ] No se presenta evidencia local o sintética como norma de toda la UAGRM o de Bolivia.
